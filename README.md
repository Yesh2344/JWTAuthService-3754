## Overview

**JWTAuthService** is a lightweight, production‑ready authentication micro‑service built with Ruby and Sinatra. 
It issues JSON Web Tokens (JWT) for authenticated users and validates them for protected endpoints.

Features:

- Secure token generation using the `jwt` gem
- Environment‑based configuration (`dotenv`)
- Structured logging with Ruby's built‑in `Logger`
- Comprehensive error handling
- RSpec test suite
- Clear separation of concerns (configuration, helpers, entry point)
